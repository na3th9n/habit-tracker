# HEVY Workout Tracker

## Overview

I'm poor and I don't want to pay for [hevy.com](Hevy) which is a workout tracker. They have their public API and any workout data preceeding the most recent 3 months locked under a paywall. However, they let you download a CSV file with all your workouts. The purpose of this project is a full-stack application that parses the CSV file, saves all the data to a database, and have a fully functional app that can do a bunch of cool features with that data.

## Running Locally

In the beginning right now and the app use to be a habit tracker but I changed it to this current idea. Project will become more organized in the future.

The project is a mono-repo with a frontend and backend.

You can directly download all the dependencies within the root directory.

```bash
npm i
```

Run the frontend and backend with the same command

```bash
npm run dev
```
